# 5. 트리와 포리스트 워크북

1. 정점이 둘 이상인 유한 트리에는 잎이 있음을 사용한다고 하겠습니다. 정점이 `n`개인 트리의 간선 수가 `n - 1`개임을 잎 하나를 제거하는 귀납법으로 완성하세요.

기저 사례 = 정점이 1개이면 간선이 없으므로, 간선 수는 `0 = 1 - 1 = n - 1`이다.

귀납 단계 = 정점이 `n`개인 트리에서 잎 하나와 그 간선을 제거하면 정점이 `n - 1`개인 트리가 남는다. 귀납 가정에 의해 남은 트리의 간선은 `n - 2`개이고, 제거한 잎과 간선을 되돌리면 정점은 `n`개, 간선은 `n - 1`개가 된다.

2. 정점 `A`, `B`, `C`, `D`와 간선 `A—B`, `B—C`, `C—A`를 생각하세요. 간선 수는 `n - 1`이지만 왜 트리가 아닌가요? 이 예가 트리 판정에서 연결성과 간선 수를 모두 확인해야 하는 이유를 설명하세요.

설명 = `A—B—C—A`로 이어지는 사이클이 있고, 정점 `D`는 아무 정점과도 연결되지 않아 전체 그래프가 연결 그래프가 아니다. 따라서 간선 수가 `n - 1`개라는 사실만으로는 트리라고 판정할 수 없으며 연결성도 함께 확인해야 한다.

3. 그래프 `A—B—C—D`가 트리인지 두 정의로 검사하세요: (a) 연결이고 사이클이 없는가, (b) 연결이고 `n - 1`개 간선이 있는가?

(a) = 모든 정점이 연결되어 있고 사이클이 없으므로 트리이다.

(b) = 정점은 `n = 4`개이고 간선은 `3 = n - 1`개이다. 그래프가 연결되어 있으므로 트리이다.
