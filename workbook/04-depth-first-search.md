# 4. 깊이 우선 탐색과 연결성 워크북

다음 무방향 그래프에서 `A`를 시작점으로 깊이 우선 탐색하세요. 이웃은 알파벳순으로 스택에 넣고, 스택의 오른쪽이 꼭대기입니다.

```text
    A
   / \
  B   C
  |
  D      E—F
```

간선은 `A—B`, `A—C`, `B—D`, `E—F`입니다.

1. 시작 스택부터 매번 정점을 하나 꺼낸 뒤의 스택까지, 스택 변화를 순서대로 쓰세요.

스택 변화 = `[A] → [B, C] → [B] → [D] → []`

2. 이 그래프의 연결 요소를 서로 겹치지 않는 정점 집합으로 쓰고, 왜 각 정점이 정확히 하나의 연결 요소에 속하는지 한 문장으로 설명하세요.

연결 요소 = `{A, B, C, D}`, `{E, F}`

설명 = 한 번 방문 표시된 정점은 이후 DFS에 다시 포함되지 않기 때문에 정점은 하나의 연결 요소에만 포함된다.

3. 경로 `A—B—C`는 사이클이 아닙니다. DFS가 `B`에서 이미 방문한 `A`를 볼 때 이를 사이클이라고 판단하면 왜 틀리는지, 그리고 삼각형 `A—B—C—A`에서는 어느 이웃이 부모 예외를 통과하는지 설명하세요.

설명 = 사이클은 세 개 이상의 정점일 때 성립한다. 이미 방문한 `A`를 보는 것은 무방향 그래프에서 하나의 간선을 반대로 본 것이므로 사이클이 아니다. 삼각형에서는 `C`가 보는 `A`가 부모가 아니다.
