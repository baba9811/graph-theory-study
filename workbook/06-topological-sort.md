# 6. 방향 비순환 그래프와 위상 정렬 워크북

1. 과목 관계가 `intro → bfs`, `intro → dfs`, `bfs → flow`, `dfs → flow`일 때, 서로 다른 유효한 과목 순서를 두 개 쓰세요.

첫 번째 순서 = `intro → bfs → dfs → flow`

두 번째 순서 = `intro → dfs → bfs → flow`

2. 비어 있지 않은 유한 DAG에 진입차수 0인 정점이 반드시 하나 있다는 것을 귀류법으로 설명하세요. 모든 정점의 진입차수가 1 이상이라고 가정한 뒤, 들어오는 간선을 계속 거꾸로 따라가면 무엇이 생기나요?

증명 = 모든 정점의 진입차수가 1 이상이라고 가정하자. 임의의 정점에서 들어오는 간선을 계속 거꾸로 따라가면 정점 수가 유한하므로 어떤 정점을 다시 만나 방향 사이클이 생긴다. 이는 DAG라는 가정과 모순이므로 진입차수 0인 정점이 반드시 존재한다.

3. `A → B → C → A`에서 Kahn 알고리즘이 왜 순서를 완성하지 못하는지 진입차수로 진단하세요. 어떤 오류를 내야 하나요?

진단 = `A`, `B`, `C`의 진입차수는 모두 1이다. Kahn 알고리즘은 진입차수 0인 정점에서 시작하지만 그런 정점이 없으므로 순서를 완성하지 못하고 `ValueError`를 내야 한다.
