# 2. 차수, 보행, 경로, 사이클 워크북

다음 무방향 그래프를 사용하세요.

```text
    A
   / \
  B---C---D
```

간선은 `A—B`, `B—C`, `C—A`, `C—D`입니다.

1. `A, B, C, D` 순서로 차수를 쓰고, 큰 차수부터 작은 차수 순으로 차수열을 쓰세요.

차수 = 2, 2, 3, 1

차수열 = [3, 2, 2, 1]

2. 다음 각 정점열을 보행, 트레일, 경로, 닫힌 보행, 사이클 중 해당하는 말로 분류하세요. 해당하지 않는 말은 쓰지 않아도 됩니다.

`A, B, C, A, B` = 보행

`D, C, A, B` = 보행, 트레일, 경로

`A, B, C, A` = 보행, 트레일, 닫힌 보행, 사이클

3. 홀수 차수 정점의 수가 항상 짝수인 이유를 악수 정리를 써서 정확히 두 문장으로 설명하세요.

답 = 악수 정리에 따르면 모든 정점의 차수 합은 간선 수의 두 배이므로 반드시 짝수이다. 짝수 차수들의 합은 짝수이고 홀수들의 합이 짝수가 되려면 홀수인 항이 짝수 개여야 하므로, 홀수 차수 정점의 개수는 짝수이다.
