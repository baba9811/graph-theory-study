# 3. 너비 우선 탐색 워크북

다음 그래프에서 `A`를 시작점으로 너비 우선 탐색하세요. 이웃은 알파벳순으로 큐에 넣습니다.

```text
    A
   / \
  B   C
   \ /
    D      E
```

간선은 `A—B`, `A—C`, `B—D`, `C—D`입니다.

1. 시작 큐부터 매번 정점을 하나 꺼낸 뒤의 큐까지, 큐의 변화를 순서대로 쓰세요.

큐 변화 = [A] -> [B, C] -> [C, D] -> [D] -> []

2. `A`에서 `D`까지의 최단 거리가 2인 이유를 BFS의 층 순서와 처음 발견 불변식을 사용해 두 문장으로 설명하세요.

설명 = A는 0층, B, C는 1층, D는 2층이고, D까지 필요한 간선 수는 최소 2개이다. BFS에서 하위 층으로 진행될 때 처음 발견하는 순간 `visited` 혹은 `distance`에 추가되므로, 처음 발견된 거리가 최단 거리가 된다.

3. 방문 표시를 큐에서 꺼낼 때가 아니라 큐에 넣을 때 해야 하는 이유를 `D`를 예로 들어 설명하세요.

설명 = `B`가 `D`를 큐에 넣을 때 발견된 정점으로 기록하면, `C`가 `D`를 큐에 넣으려 할 때 이미 발견된 정점으로 표시되어 있으므로 큐에 중복 삽입하지 않는다.
