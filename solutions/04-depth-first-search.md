# 4. 깊이 우선 탐색과 연결성 풀이

1. 스택 변화는 `[A] → [B, C] → [B] → [D] → []`입니다. 오른쪽이 꼭대기이므로 `A`에서 `B`, `C`를 차례로 넣으면 마지막에 들어간 `C`가 먼저 나옵니다. `C`를 끝낸 뒤 스택에 남은 `B`로 되돌아가 `D`를 탐색합니다.

2. 연결 요소는 `{A, B, C, D}`와 `{E, F}`입니다. 새 DFS는 아직 방문하지 않은 정점에서만 시작하고 방문한 정점은 다시 다른 DFS에 넣지 않으므로, 각 정점은 정확히 하나의 연결 요소에 속합니다.

3. `B`에서 보는 `A`는 `B`를 처음 발견한 부모 정점이라서 같은 무방향 간선을 반대 방향으로 확인한 것뿐입니다. 삼각형에서는 `C`가 이미 방문한 `A`를 볼 때 `C`의 부모는 `B`이므로 부모 예외가 적용되지 않고 사이클을 찾습니다.

`connected_components`와 `has_cycle`은 모두 DFS를 사용합니다. 정점은 한 번 방문하고 인접 간선은 한 번씩 확인하므로 시간 복잡도는 `O(|V| + |E|)`입니다.
