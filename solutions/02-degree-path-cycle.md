# 2. 차수, 보행, 경로, 사이클 풀이

1. 차수는 `A: 2`, `B: 2`, `C: 3`, `D: 1`이고, 차수열은 `3, 2, 2, 1`입니다.

2. `A, B, C, A, B`는 보행입니다. `A—B`를 두 번 지나므로 트레일도 경로도 아닙니다. `D, C, A, B`는 정점과 간선을 모두 반복하지 않으므로 경로이며, 따라서 트레일과 보행이기도 합니다. `A, B, C, A`는 닫힌 보행이고, 세 개의 서로 다른 정점 `A`, `B`, `C`를 지나며 어떤 간선도 반복하지 않으므로 사이클이기도 합니다.

3. 악수 정리에 따라 모든 정점의 차수 합은 각 간선의 두 끝점을 세므로 짝수입니다. 짝수 차수들을 제외한 뒤에도 합이 짝수여야 하므로, 홀수 차수의 합이 짝수가 되게 하는 홀수 차수 정점의 개수는 짝수입니다.

`degree_map`은 각 정점의 이웃 집합 길이를 차수로 바꾼 딕셔너리 컴프리헨션입니다. `is_valid_path`는 빈 목록과 반복 정점을 먼저 거르고, 모든 정점이 그래프에 있는지 확인한 뒤, 이웃한 두 정점마다 실제 간선이 있는지 검사합니다.
