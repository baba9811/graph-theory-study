# 1. 그래프 기초와 표현 풀이

1. `V = {서울, 시청, 광화문}`이고 `E = {{서울, 시청}, {시청, 광화문}}`입니다. 역이 정점이고, 서로 직접 잇는 노선이 무방향 간선입니다.

2. 인접 리스트는 `서울: {시청}`, `시청: {서울, 광화문}`, `광화문: {시청}`입니다. 정점 순서가 `서울, 시청, 광화문`이면 인접 행렬은 다음과 같습니다.

```text
[ [0, 1, 0],
  [1, 0, 1],
  [0, 1, 0] ]
```

3. 연결이 드문 사회 관계망에는 인접 리스트가 알맞습니다. 실제 친구 관계만 저장하여 `O(|V| + |E|)` 공간을 쓰지만, 인접 행렬은 친구가 아닌 쌍까지 포함한 `O(|V|²)` 칸을 저장합니다.

`build_adjacency_list`의 첫 딕셔너리 컴프리헨션은 모든 정점을 빈 이웃 집합으로 만들어 고립 정점도 보존합니다. 간선을 순회하는 루프는 끝점이 기존의 서로 다른 정점인지 확인한 뒤 출발점의 이웃에 도착점을 넣고, 무방향일 때는 반대 방향도 넣습니다.

`to_adjacency_matrix`는 먼저 정점 순서가 그래프의 모든 정점을 한 번씩 담는지 검사합니다. `enumerate`를 순회해 정점과 행·열 번호의 대응을 만들고, 행렬의 각 행을 0으로 초기화합니다. 마지막 바깥 루프는 각 정점을, 안쪽 루프는 그 정점의 이웃을 순회하여 해당 행과 열의 값을 `1`로 바꿉니다.
