# 해설 08. 다익스트라 최단 경로

## 1. 완화 표

`A` 뒤에는 `B=4` (부모 `A`), `C=1` (부모 `A`), `D=∞`입니다. `C` 뒤에는 `B=3` (부모 `C`), `C=1` (부모 `A`), `D=6` (부모 `C`)입니다. `C → B`와 `C → D`를 지나는 후보가 기존 값보다 작아서 완화됩니다.

## 2. 확정 거리 불변식

최신 heap 항목 중 가장 작은 거리를 먼저 꺼내므로, 아직 처리하지 않은 정점으로 돌아가는 경로는 출발부터 그보다 작을 수 없습니다. 이후 간선의 가중치가 0 이상이면 그 경로의 합도 줄어들지 않습니다. 따라서 꺼낸 거리보다 더 짧은 경로가 뒤늦게 나올 수 없습니다. 음수 간선이 있으면 큰 거리에서 출발한 뒤 더 작은 값으로 내려갈 수 있어 이 논리가 깨집니다.

## 3. 오래된 heap 항목

`distance != distances[current]`이면 `(4, "B")`를 건너뜁니다. 현재 기록된 최선 거리는 이미 `3`이므로 `(4, "B")`는 예전 후보입니다. 이 검사가 없으면 같은 정점의 이웃을 불필요하게 다시 처리합니다. 거리 자체는 더 짧을 때만 갱신하므로 보통 결과는 같지만, 오래된 항목이 많으면 시간이 낭비됩니다.

## 구현 핵심

각 정점의 현재 최선 거리만 `distances`에 보관하고, 더 좋은 후보는 heap에 새로 넣습니다. 인접 맵에서 간선마다 한 번의 완화를 시도하고 heap 연산은 `O(log |V|)`이므로 시간 복잡도는 `O((|V| + |E|) log |V|)`입니다.
