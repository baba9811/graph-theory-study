# 07. 강한 연결 요소

## 학습 안내

- **학습 목표:** Kosaraju의 두 DFS로 SCC를 나누고 응축 그래프의 성질을 설명합니다.
- **새 용어:** SCC, 강한 연결, 약한 연결, 전치 그래프, 종료 순서, 응축 그래프
- **흔한 오해:** 방향을 지웠을 때 연결된 것만으로 강하게 연결된 것은 아닙니다.
- **구현 전제:** 모든 방향 간선의 도착점은 그래프의 키입니다.
- **완료 기준:** 두 번의 DFS를 손으로 추적하고 `strongly_connected_components` 테스트를 통과합니다.
- **35분 배분:** 목표·용어 5분 + 정의·예제 7분 + 손풀이·증명 7분 + Python 구현 12분 + 테스트·복습 4분

## 약한 연결과 강한 연결

유향 그래프에서 두 정점이 **강하게 연결**되려면 양방향 경로가 모두 있어야 합니다. 즉 `u`에서 `v`로 갈 수 있고, `v`에서 `u`로도 갈 수 있어야 합니다.

반대로 간선 방향을 지워 무방향 그래프로 보았을 때만 연결되면 **약하게 연결**되어 있다고 합니다. `A → B` 하나만 있어도 `A`, `B`는 약하게 연결이지만, `B`에서 `A`로 돌아갈 수 없으므로 강하게 연결은 아닙니다.

SCC는 서로 강하게 연결된 정점들의 최대 집합입니다. 한 정점도 자기 자신으로 가는 길이 있으므로, 어느 SCC에도 속하지 못하는 정점은 없습니다.

## 전치 그래프와 종료 순서

그래프의 **전치(transpose) 그래프**는 모든 간선의 방향을 뒤집은 그래프입니다. `A → B`는 전치 그래프에서 `B → A`가 됩니다.

Kosaraju 알고리즘은 DFS를 두 번 합니다.

1. 원래 그래프에서 DFS를 하고, 한 정점의 탐색이 끝나는 순간을 `finish_order`에 기록합니다.
2. 전치 그래프에서 `finish_order`의 **역순**으로 DFS를 시작합니다. 한 번의 DFS가 모은 정점들이 하나의 SCC입니다.

예를 들어 `A ↔ B`, `B → C`, `C ↔ D`, `D → E`라면 첫 DFS는 각 정점의 종료 순서를 만든 뒤 끝납니다. 그 순서를 뒤집어 전치 그래프에서 시작하면, 처음 DFS는 `{A, B}`, 다음은 `{C, D}`, 마지막은 `{E}`만 모읍니다. 이미 찾은 SCC 밖으로 나가는 전치 간선이 있더라도, 역순이 먼저 시작해야 할 SCC를 골라 주므로 다른 묶음으로 새어 나가지 않습니다.

## 응축 그래프는 DAG

각 SCC를 정점 하나로 **수축(contract)**하고 SCC 사이의 간선만 남긴 그래프를 응축 그래프라고 합니다. 이것은 반드시 DAG(방향 사이클이 없는 그래프)입니다.

만약 응축 그래프에 방향 사이클이 있다면, 그 사이클의 SCC들은 서로 차례로 도달할 수 있고 다시 출발점으로 돌아올 수 있습니다. 따라서 그 SCC들은 사실 하나의 더 큰 강한 연결 요소여야 합니다. 이는 각각이 최대 집합이라는 정의와 모순입니다.

## 복잡도

첫 DFS, 전치 그래프 만들기, 둘째 DFS 모두 정점과 간선을 한 번씩만 다룹니다. 전체 시간 복잡도는 `O(|V| + |E|)`이고, 추가 공간도 `O(|V| + |E|)`입니다.
