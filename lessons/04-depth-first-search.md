# 4. 깊이 우선 탐색과 연결성

**깊이 우선 탐색(Depth-First Search, DFS)** 은 한 이웃으로 가능한 멀리 내려간 뒤, 더 갈 곳이 없을 때 직전 갈림길로 되돌아오는 탐색입니다. BFS가 큐의 FIFO(먼저 들어온 항목이 먼저 나옴)로 가까운 층부터 넓히는 것과 달리, DFS는 **스택(stack)** 의 LIFO(Last In, First Out, 후입선출: 나중에 들어온 항목이 먼저 나옴)를 씁니다.

다음 무방향 그래프를 `A`에서 탐색한다고 하겠습니다. 이웃은 알파벳순으로 스택에 넣습니다.

```text
    A
   / \
  B   C
  |
  D      E—F
```

간선은 `A—B`, `A—C`, `B—D`, `E—F`입니다. 스택의 오른쪽이 꼭대기라면 `A`를 꺼낸 뒤 `B`, `C`를 넣으므로 다음에는 `C`를 먼저 방문합니다. 한 갈래를 끝까지 탐색한 뒤에는 스택에 남아 있던 정점으로 돌아가므로, 이 과정이 **되돌아가기(backtracking)** 입니다.

```text
처음:       [A]
A를 꺼냄:   [B, C]
C를 꺼냄:   [B]
B를 꺼냄:   [D]
D를 꺼냄:   []
```

`A`에서 시작한 DFS는 `A, B, C, D`만 방문합니다. 서로 경로로 갈 수 있는 정점의 최대 집합을 **연결 요소(connected component)** 라고 합니다. 따라서 이 그래프의 연결 요소는 `{A, B, C, D}`와 `{E, F}`입니다. 아직 방문하지 않은 정점을 새 시작점으로 골라 DFS를 다시 실행하면 모든 연결 요소를 나눌 수 있습니다. 한 정점은 처음 방문된 한 번의 탐색에만 들어가므로 정확히 하나의 연결 요소에 속합니다.

무방향 그래프에서 DFS로 사이클을 검사할 때는 스택에 `(현재 정점, 부모 정점)`을 함께 저장합니다. `B`에서 `A`를 볼 때 `A`는 이미 방문했지만, `A`는 `B`를 발견한 부모이므로 간선을 반대 방향에서 다시 본 것뿐이며 사이클이 아닙니다. 반대로 이미 방문한 이웃이 부모가 아니라면, DFS 트리 밖의 간선이므로 사이클이 있습니다. 예를 들어 삼각형 `A—B—C—A`에서 `C`가 이미 방문한 `A`를 만나면 `A`는 `C`의 부모 `B`가 아니므로 사이클입니다.

방문 표시는 정점을 스택에 넣을 때 합니다. 각 정점은 한 번만 넣고, 각 간선은 이웃을 확인할 때만 살피므로 인접 리스트에서 연결 요소 분할과 사이클 검사는 모두 **`O(|V| + |E|)`** 입니다.
