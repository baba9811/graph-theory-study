# 3. 너비 우선 탐색

## 학습 안내

- **학습 목표:** BFS 층을 추적하고 무가중 최단 거리와 경로를 복원합니다.
- **새 용어:** 너비 우선 탐색, 큐, FIFO, 층, 부모
- **흔한 오해:** 큐에서 꺼낼 때 방문 표시하면 같은 정점이 여러 번 들어갈 수 있습니다.
- **구현 전제:** 시작 정점은 그래프의 키이고 모든 간선 가중치는 동일하다고 봅니다.
- **완료 기준:** 큐 변화를 쓰고 `bfs`, `reconstruct_path` 테스트를 통과합니다.
- **35분 배분:** 목표·용어 5분 + 정의·예제 7분 + 손풀이·증명 7분 + Python 구현 12분 + 테스트·복습 4분

**너비 우선 탐색(Breadth-First Search, BFS)** 은 시작 정점 가까이에 있는 정점부터 차례로 방문하는 방법입니다. 시작점에서 한 간선만 건너면 닿는 정점을 모두 살핀 뒤, 두 간선이 필요한 정점으로 넓혀 갑니다.

다음 그래프에서 `A`에서 탐색을 시작해 보겠습니다.

```text
    A
   / \
  B   C
   \ /
    D      E
```

간선은 `A—B`, `A—C`, `B—D`, `C—D`이고 `E`는 연결되지 않은 정점입니다. BFS는 아직 처리하지 않은 정점을 **큐(queue)** 에 넣습니다. 큐는 먼저 들어온 항목이 먼저 나오는 FIFO(First In, First Out) 자료구조입니다.

정점을 큐에서 꺼내 이웃을 처음 발견하면, 그 이웃의 거리와 부모를 기록하고 큐 뒤에 넣습니다. 이 그래프에서 이웃을 알파벳순으로 보면 큐의 변화는 다음과 같습니다.

```text
처음:       [A]
A를 꺼냄:   [B, C]     (B, C의 거리: 1)
B를 꺼냄:   [C, D]     (D의 거리: 2, 부모: B)
C를 꺼냄:   [D]        (D는 이미 발견함)
D를 꺼냄:   []
```

`E`는 `A`에서 갈 수 없으므로 거리 딕셔너리에 들어가지 않습니다. `D`의 부모가 `B`이면 부모를 거꾸로 따라 `D → B → A`를 얻고, 순서를 뒤집어 최단 경로 `A → B → D`를 복원할 수 있습니다. `C`를 통한 경로도 길이 2이지만, 먼저 발견한 `B`를 부모로 기록했으므로 한 가지 최단 경로가 저장됩니다.

핵심 불변식은 다음과 같습니다. **정점이 처음 발견될 때 기록한 거리는 시작점에서 그 정점까지의 최단 간선 수입니다.** 큐는 거리가 0, 1, 2, ...인 층(layer) 순서로 정점을 꺼냅니다. 따라서 어떤 정점을 처음 발견한 경로보다 더 짧은 경로가 나중에 나타날 수 없습니다. 이 때문에 정점을 큐에 넣는 순간 방문 표시를 하면 중복 삽입도 막을 수 있습니다.

각 정점은 한 번 큐에 들어가고, 각 간선은 이웃을 확인할 때 많아야 두 번 살핍니다. 따라서 인접 리스트 표현에서 BFS의 시간 복잡도는 **`O(|V| + |E|)`** 입니다.
