# 최소 신장 트리와 Kruskal 알고리즘

## 학습 안내

- **학습 목표:** 컷 성질과 분리 집합을 사용해 Kruskal 최소 신장 트리를 만듭니다.
- **새 용어:** MST, 컷, 안전한 간선, 분리 집합, 경로 압축, rank
- **흔한 오해:** MST는 한 시작점에서 각 정점까지의 최단 경로 트리가 아닙니다.
- **구현 전제:** 정점 집합은 비어 있지 않고 모든 간선은 기존 정점을 잇는 무방향 가중 간선입니다.
- **완료 기준:** 간선 선택을 추적하고 `DisjointSet`, `kruskal` 테스트를 통과합니다.
- **35분 배분:** 목표·용어 5분 + 정의·예제 7분 + 손풀이·증명 7분 + Python 구현 12분 + 테스트·복습 4분

**최소 신장 트리(MST, Minimum Spanning Tree)** 는 연결된 무방향 가중 그래프의 모든 정점을 연결하면서 간선 가중치 합이 가장 작은 트리입니다. `spanning`은 모든 정점을 덮는다는 뜻이고, 트리이므로 간선은 정확히 `|V|-1`개이며 사이클이 없습니다.

## 최단 경로 트리와는 다른 목표

시작점 `A`에서 만든 최단 경로 트리는 `A`에서 각 정점까지의 거리를 각각 최소화합니다. MST는 시작점이 없고, 선택한 **전체 간선의 합**을 최소화합니다. 따라서 한 그래프에서 두 트리가 서로 다를 수 있습니다. 예를 들어 `A-B(2), A-C(2), B-C(1)`에서는 `A` 기준 최단 경로 트리가 `A-B, A-C`를 고를 수 있지만, MST는 `B-C`와 `A-B`를 골라 합 `3`을 만듭니다.

## 컷과 안전한 간선

정점 집합을 겹치지 않는 두 부분 `S`와 `V-S`로 나눈 것을 **컷(cut)** 이라 합니다. 현재까지 고른 안전한 간선 집합 `A`를 포함하는 MST가 있고 그 간선들이 컷을 가로지르지 않는다면, 가장 가벼운 횡단 간선까지 `A`와 함께 포함하는 MST가 적어도 하나 존재합니다. 이것이 **컷 성질(cut property)** 입니다. 임의의 기존 MST에 간선을 그대로 더한다는 뜻은 아니며, 필요하면 같은 무게 이상의 횡단 간선을 교환합니다.

## Kruskal의 선택 과정

Kruskal 알고리즘은 간선을 가중치 오름차순으로 훑습니다. 간선의 양 끝점이 서로 다른 연결 요소에 있으면 선택하고 합칩니다. 같은 요소에 있으면 그 간선을 넣는 순간 사이클이 생기므로 건너뜁니다.

`A-B(1), C-D(1), B-C(2), A-C(4), B-D(5)`를 순서대로 보면 `A-B`, `C-D`, `B-C`를 선택해 가중치 합 `4`의 트리를 얻습니다. 이후 간선은 더 볼 필요가 없습니다.

연결 요소를 빠르게 관리하려고 **분리 집합(disjoint set union)** 을 씁니다. `find`는 정점의 대표를 찾고, **경로 압축(path compression)** 은 찾는 도중 만난 정점이 대표를 바로 가리키게 합니다. `union`은 **rank**가 작은 트리를 큰 트리 아래 붙입니다. 이 둘 덕분에 집합 연산은 사실상 상수 시간이며, 전체 시간은 정렬이 지배하는 `O(|E| log |E|)`입니다.
