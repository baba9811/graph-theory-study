# 08. 다익스트라 최단 경로

## 학습 안내

- **학습 목표:** 완화와 최소 힙으로 비음수 가중치 최단 경로를 구합니다.
- **새 용어:** 가중치, 잠정 거리, 완화, 확정 거리, 오래된 힙 항목
- **흔한 오해:** 간선 수가 적은 경로나 처음 발견한 경로가 항상 최소 비용인 것은 아닙니다.
- **구현 전제:** 시작점과 모든 이웃은 그래프의 키이고 가중치는 0 이상입니다.
- **완료 기준:** 완화 표와 탐욕 불변식을 쓰고 `dijkstra` 테스트를 통과합니다.
- **35분 배분:** 목표·용어 5분 + 정의·예제 7분 + 손풀이·증명 7분 + Python 구현 12분 + 테스트·복습 4분

## 가중치와 경로 길이

간선 `u → v`에 붙은 수를 **가중치(weight)**라고 합니다. 경로의 가중치는 그 경로가 지나는 간선 가중치의 합입니다. 예를 들어 `A → C → B → D`의 가중치가 `1 + 2 + 1 = 4`라면, 간선 수가 더 적은 `A → B → D`의 가중치 `4 + 1 = 5`보다 더 짧은 경로입니다.

따라서 BFS처럼 먼저 발견한 경로가 항상 최단인 것은 아닙니다. 다익스트라는 지금까지 알려진 가장 짧은 거리, 즉 **잠정 거리(tentative distance)**가 가장 작은 정점을 먼저 고릅니다.

## 완화와 heap

**완화(relaxation)**는 현재 정점 `u`를 거쳐 이웃 `v`로 가는 후보 거리 `distance[u] + weight(u, v)`가 기존 `distance[v]`보다 작을 때, `distance[v]`와 부모를 갱신하는 일입니다.

다음 그래프를 `A`에서 시작해 보세요.

```text
A --4--> B --1--> D
|        ^
1        |2
v        |
C --5--> D
```

초기 heap은 `[(0, "A")]`입니다.

| heap에서 꺼낸 항목 | 완화 뒤 바뀐 거리 | 새 heap 후보 |
| --- | --- | --- |
| `(0, A)` | `B=4`, `C=1` | `(1, C)`, `(4, B)` |
| `(1, C)` | `B=3`, `D=6` | `(3, B)`, `(6, D)`, 이전 `(4, B)` |
| `(3, B)` | `D=4` | `(4, B)`, `(4, D)`, 이전 `(6, D)` |

Python의 `heapq`는 값을 제자리에서 줄이지 않습니다. 그래서 `B`의 거리 `4`를 `3`으로 바꿀 때 새 `(3, "B")`를 넣고 예전 `(4, "B")`는 남겨 둡니다. 꺼낸 `distance`가 현재 `distances[current]`와 다르면 **오래된 항목(stale heap entry)**이므로 건너뜁니다.

## 탐욕 선택과 확정 거리

heap에서 꺼낸 항목이 오래되지 않았다면, 그 정점의 거리는 **확정(settled)**됩니다. 핵심 불변식은 다음과 같습니다.

> 확정된 정점 `u`의 `distances[u]`는 시작점에서 `u`까지의 실제 최단 거리다.

왜냐하면 아직 확정되지 않은 경로가 `u`보다 더 짧으려면 그 경로가 먼저 어떤 미확정 정점을 지나야 합니다. heap은 `u`보다 작은 잠정 거리를 가진 정점을 먼저 꺼내므로 그런 정점은 이미 처리됐어야 합니다. 또한 이후에 붙는 간선의 가중치는 음수가 아니므로, 더 큰 거리에서 출발해 `u`보다 작은 총거리로 내려갈 수 없습니다. 이것이 가장 작은 잠정 거리를 고르는 탐욕 선택이 안전한 이유입니다.

## 음수 가중치의 경계

음수 간선이 있으면 위 증명이 무너집니다. 예를 들어 `A → B`의 가중치가 `1`, `A → C`가 `2`, `C → B`가 `-3`이면, 다익스트라는 먼저 `B`를 거리 `1`로 확정하지만 실제 최단 거리는 `A → C → B`의 `-1`입니다. 그러므로 이 구현은 음수 가중치를 만나면 `ValueError`를 발생시킵니다. 음수 간선이 필요하면 Bellman-Ford 알고리즘을 사용해야 합니다.

## 복잡도

인접 맵의 각 간선은 완화될 때 heap에 한 번 들어갈 수 있습니다. 이진 heap의 삽입과 삭제는 `O(log |V|)`이므로 전체 시간은 `O((|V| + |E|) log |V|)`이고, 거리·부모·heap에는 `O(|V| + |E|)` 공간이 필요합니다.
