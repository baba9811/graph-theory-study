# 17. 그래프 색칠과 평면 그래프의 간선 상한

## 학습 안내

- **학습 목표:** 결정적 탐욕 색칠을 만들고 단순 평면 그래프의 간선 상한을 유도합니다.
- **새 용어:** 올바른 색칠, 색칠수, 탐욕 휴리스틱, 평면 그래프, 면, 오일러 공식
- **흔한 오해:** 간선 상한을 만족한다고 평면성이 증명되거나 탐욕 색 수가 최소가 되지는 않습니다.
- **구현 전제:** 색칠 입력은 무방향 단순 그래프이며 간선 상한은 정점·간선 수가 주어진 단순 그래프에만 적용합니다.
- **완료 기준:** 두 색칠 순서와 상한 유도를 쓰고 두 공개 함수 테스트를 통과합니다.
- **35분 배분:** 목표·용어 5분 + 정의·예제 7분 + 손풀이·증명 7분 + Python 구현 12분 + 테스트·복습 4분

## 올바른 색칠과 색칠수

정점의 **올바른 색칠**(proper coloring)은 간선으로 이어진 두 정점에 서로 다른 색을 배정하는 것입니다. 색은 이름 대신 `0, 1, 2, ...` 같은 정수로 나타내도 됩니다. 그래프를 올바르게 색칠하는 데 필요한 최소 색 수를 **색칠수**(chromatic number)라고 하며 `χ(G)`로 씁니다.

올바른 색칠 하나를 찾는 것과 색칠수를 구하는 것은 다릅니다. 어떤 알고리즘이 세 가지 색으로 올바르게 색칠했다고 해서 두 가지 색으로는 불가능하다는 뜻은 아닙니다. 최소 색 수를 찾는 일반 그래프 색칠 문제는 계산적으로 어렵기 때문에, 이번 수업에서는 빠르게 올바른 답 하나를 만드는 탐욕 휴리스틱을 사용합니다.

## 결정적인 탐욕 색칠

`greedy_coloring`은 차수가 큰 정점부터 처리하고, 차수가 같으면 정점 이름순으로 처리합니다. 각 정점에는 이미 색칠된 이웃이 쓰지 않은 가장 작은 음이 아닌 정수를 배정합니다. 정렬 규칙이 고정되어 있으므로 같은 입력에는 같은 결과가 나옵니다.

이 방법은 항상 올바른 색칠을 만들지만 색 수를 최소화한다고 보장하지 않습니다. 예를 들어 왼쪽 정점 `A, B, C`와 오른쪽 정점 `a, b, c`가 있고 서로 같은 글자의 대소문자 쌍만 연결되지 않은 이분 그래프를 생각해 봅시다. 순서 `A, a, B, b, C, c`에서는 세 색을 쓰지만, 순서 `A, B, C, a, b, c`에서는 두 색이면 충분합니다. 탐욕 결과는 정점 순서에 의존하므로 색칠수의 증명이 아닙니다.

## 평면 그래프, 면, 오일러 공식

**평면 그래프**(planar graph)는 간선들이 끝점이 아닌 곳에서 서로 교차하지 않도록 평면에 그릴 수 있는 그래프입니다. 현재 그림에 교차가 있다는 사실만으로 비평면이라고 할 수는 없습니다. 다른 배치로 교차를 없앨 수도 있기 때문입니다.

교차 없이 그린 평면 그래프에서 간선이 평면을 나눈 각 영역을 **면**(face)이라고 합니다. 바깥의 무한히 넓은 영역도 면 하나로 셉니다. 연결된 평면 그래프의 정점 수, 간선 수, 면 수를 각각 `|V|`, `|E|`, `|F|`라 하면 **오일러 공식**은 다음과 같습니다.

`|V| - |E| + |F| = 2`

예를 들어 정점 4개와 간선 5개인 연결 평면 그래프는 `4 - 5 + |F| = 2`이므로 면이 3개입니다.

## 단순 평면 그래프의 간선 상한

정점이 적어도 3개인 연결 **단순** 평면 그래프를 생각합시다. 단순 그래프에는 루프와 평행 간선이 없으므로 각 면의 경계에는 적어도 세 간선이 필요합니다. 모든 면의 경계 길이를 더하면 각 간선이 양쪽에서 두 번 세어져 `2|E|`가 되므로

`3|F| ≤ 2|E|`

입니다. 오일러 공식에서 `|F| = 2 - |V| + |E|`를 대입하면

`3(2 - |V| + |E|) ≤ 2|E|`

이고, 정리하여

`|E| ≤ 3|V| - 6`

을 얻습니다. 연결되지 않은 단순 평면 그래프도 성분 사이에 교차 없는 간선을 더해 연결할 수 있으므로 같은 상한을 만족합니다.

정점이 3개보다 적으면 `3|V|-6`을 그대로 쓰지 않습니다. 단순 그래프가 가질 수 있는 최대 간선 수 `|V|(|V|-1)/2`를 사용합니다.

가장 중요한 점은 이 상한이 평면이기 위한 **필요조건일 뿐 충분조건이 아니라는 것**입니다. 상한을 위반하면 비평면이라고 결론 낼 수 있지만, 상한을 만족해도 평면이라고 결론 낼 수 없습니다. `K₃,₃`은 정점 6개와 간선 9개라 `9 ≤ 12`를 만족하지만 비평면입니다. 따라서 `within_planar_edge_bound`는 비평면 후보를 걸러 내는 필요조건 필터이지 평면성 판정 함수가 아닙니다.
