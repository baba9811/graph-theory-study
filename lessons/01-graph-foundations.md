# 1. 그래프 기초와 표현

그래프는 **정점(vertex)** 과 **간선(edge)** 으로 관계를 나타내는 수학적 모델입니다. 정점은 역, 사람, 도시처럼 대상을 뜻하고, 간선은 두 대상 사이의 연결을 뜻합니다. 그래프를 `G = (V, E)`라고 쓰면 `V`는 정점들의 집합, `E`는 간선들의 집합입니다.

이 과정은 우선 정점 수와 간선 수가 유한하고, 한 정점을 자기 자신에게 잇는 간선이나 같은 두 정점 사이의 중복 간선이 없는 **유한 단순 그래프(finite simple graph)** 부터 다룹니다.

- **무방향 그래프(undirected graph)**: `A—B`처럼 연결에 방향이 없습니다. `A`가 `B`와 이웃이면 `B`도 `A`와 이웃입니다.
- **방향 그래프(directed graph)**: `A → B`처럼 출발점과 도착점이 구분됩니다. `A → B`가 있어도 `B → A`가 자동으로 생기지는 않습니다.

## 손으로 따라가기

경로 `A—B—C`를 무방향 그래프로 보겠습니다.

```text
V = {A, B, C}
E = {{A, B}, {B, C}}
```

**인접 리스트(adjacency list)** 는 각 정점에 바로 연결된 이웃을 적습니다.

```text
A: {B}
B: {A, C}
C: {B}
```

**인접 행렬(adjacency matrix)** 은 행과 열에 같은 정점 순서 `A, B, C`를 놓고, 연결되어 있으면 `1`, 아니면 `0`을 넣는 표입니다.

```text
    A B C
A [ 0 1 0 ]
B [ 1 0 1 ]
C [ 0 1 0 ]
```

정점이 `|V|`, 간선이 `|E|`개일 때 인접 리스트는 정점 목록과 실제 연결만 저장하므로 `O(|V| + |E|)` 공간을 씁니다. 인접 행렬은 연결이 드문 경우에도 모든 칸을 저장하므로 `O(|V|²)` 공간을 씁니다. 따라서 친구 관계처럼 연결이 드문 그래프에는 보통 인접 리스트가 알맞고, 모든 두 정점의 연결 여부를 즉시 표에서 보고 싶을 때는 인접 행렬이 편리합니다.
