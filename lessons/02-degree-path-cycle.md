# 2. 차수, 보행, 경로, 사이클

그래프에서 한 정점에 직접 닿아 있는 간선의 수를 그 정점의 **차수(degree)** 라고 합니다. 무방향 그래프에서는 인접 리스트의 이웃 수가 바로 차수입니다.

다음 하나의 그래프를 계속 사용하겠습니다.

```text
    A
   / \
  B---C---D
```

간선은 `A—B`, `B—C`, `C—A`, `C—D`입니다. 따라서 차수는 `A: 2`, `B: 2`, `C: 3`, `D: 1`입니다.

정점을 간선을 따라 차례로 방문한 목록을 **보행(walk)** 이라고 합니다. 보행에서는 정점과 간선을 다시 지나도 됩니다. 같은 간선을 두 번 지나지 않는 보행은 **트레일(trail)** 이고, 같은 정점을 두 번 지나지 않는 보행은 **경로(path)** 입니다. 경로는 당연히 트레일이고, 트레일은 보행입니다.

- `A, B, C, A, B`는 보행이지만 `A—B`를 두 번 지나므로 트레일이 아닙니다.
- `D, C, A, B`는 정점도 간선도 반복하지 않으므로 경로입니다.
- 시작 정점과 끝 정점이 같은 보행은 **닫힌 보행(closed walk)** 입니다.
- 시작 정점으로 돌아오되, 시작과 끝을 제외한 정점을 반복하지 않는 닫힌 보행은 **사이클(cycle)** 입니다. `A, B, C, A`가 그 예입니다.

## 악수 정리

모든 정점의 차수를 더하면 간선 수의 두 배가 됩니다.

```text
2 + 2 + 3 + 1 = 8 = 2 × 4
```

이는 간선 하나가 언제나 양 끝점에 하나씩 기여하기 때문입니다. 이 사실을 **악수 정리(handshaking lemma)** 라고 합니다. 차수의 합은 짝수이므로, 홀수 차수를 가진 정점의 개수도 짝수여야 합니다. 홀수들을 더한 값이 짝수가 되려면 홀수의 개수가 짝수여야 하기 때문입니다.
