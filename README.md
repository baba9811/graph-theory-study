# 그래프 이론 학습

한국어로 진행하는 대화형 그래프 이론 커리큘럼입니다.

## 시작하기

```sh
uv sync
```

Codex 채팅에서 먼저 `/next`를 입력하세요. 진행 중인 수업이 있으면 `/next`는 그 수업을 재개하고, 없으면 아직 시작하지 않은 가장 낮은 번호의 수업을 시작합니다. `/done`은 현재 수업의 검사를 실행하고, 성공하면 진행 상태를 갱신하여 자동 커밋합니다.

학습자 수업 하나만 검사하려면 다음을 실행합니다.

```sh
uv run pytest tests/test_lesson_01.py -v
```

정답 키로 검증하려면 다음을 실행합니다.

```sh
GRAPH_STUDY_SOLUTIONS=1 uv run pytest -v
```

기본 전체 테스트는 모든 학습자 연습 문제가 완료되기 전까지 실패하는 것이 정상입니다.

## 디렉터리

- `exercises/`: 학습자가 작성하는 연습 문제
- `solutions/`: 연습 문제의 정답 키
- `tests/`: 수업별 및 프로젝트 계약 테스트
- `PROGRESS.md`: 현재 수업과 수업별 진행 상태
